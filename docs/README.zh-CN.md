# windowcat 安装与使用

让一只像素白猫住在 Mac 窗口边缘。支持简体中文、English、日本語。

## 安装

1. 在 [Releases](https://github.com/kokoro-ele/window-cat/releases/latest) 下载 `windowcat-macOS-arm64.zip`。需要 macOS 13 或以上、Apple Silicon（M1 或更新）芯片。Intel Mac 可按[源码构建教程](BUILD.md)自行编译。
2. 解压，把 **windowcat.app** 拖进「应用程序」。
3. 双击打开，查看屏幕顶部菜单栏的猫图标。程序没有主窗口，也不在 Dock 中显示。
4. 此早期版本使用临时签名，尚未通过 Apple 公证。若系统拦截，先确认来自本仓库，在尝试打开后进入「系统设置 → 隐私与安全性」，对这个应用选择「仍要打开」，再按系统提示确认。不要关闭系统整体安全保护。公司管理的 Mac 可能不允许运行。


## 从顶部菜单栏放猫

1. 打开 Finder、浏览器等普通应用窗口。
2. **按住顶部菜单栏的小猫图标，直接拖到目标窗口。** 绿色边框表示当前目标。
3. 松开鼠标，小猫就会在这个窗口边缘活动。
4. 单击菜单栏图标打开菜单，在「窗口里的猫」选中一只，然后切换散步、小球、逗猫棒或打盹。

每个窗口一只，最多 12 只。拖到已有猫的窗口会选中原来的猫。猫固定跟随这个窗口，切换应用不会换目标；窗口移动或缩放时跟随，最小化或不可见时隐藏，关闭后收回。退出应用后不保留绑定关系。猫和玩具不阻挡点击。

菜单还可暂停、调速、开启自动打盹、收回小猫、切换语言或退出。语言立即生效并保存。

## 权限与常见问题

- 基础放猫与跟随**不需要辅助功能或屏幕录制权限**。应用只读取窗口位置、编号和进程信息，不截图、不读文档内容、不联网。
- 「增强窗口跟踪（可选）」使用辅助功能事件通知。选择使用时，在「系统设置 → 隐私与安全性 → 辅助功能」允许当前副本并重启程序；不授权也可使用基础跟踪。
- 打开后没看到猫：先从顶部菜单栏拖到普通窗口；启动本身不会自动放猫。
- 菜单栏看不到图标：检查是否被刘海或拥挤的菜单栏遮住，为图标留出位置。
- 猫消失：把绑定的窗口恢复到可见位置，避开遮挡。Mission Control、台前调度、多显示器、全屏和特殊系统浮层仍有兼容性边界。
- 遇到问题可[提交 Issue](https://github.com/kokoro-ele/window-cat/issues)，附 macOS 版本、机型和复现步骤，避免上传含私人内容的截图。
