# windowcat のインストールと使い方

Mac のウインドウのふちで歩いたり眠ったりする、小さなピクセル猫です。日本語・English・简体中文に対応しています。

## インストール

1. [Releases](https://github.com/kokoro-ele/window-cat/releases/latest) から `windowcat-macOS-arm64.zip` をダウンロードします。macOS 13 以降、Apple Silicon（M1 以降）が必要です。Intel Mac は[ソースからビルド](BUILD.md)できます。
2. ZIP を展開し、**windowcat.app** を「アプリケーション」へ移動します。
3. 起動すると画面上部のメニューバーに猫が表示されます。メインウインドウや Dock アイコンは表示されません。
4. この初期版はアドホック署名のみで、Apple の公証を受けていません。ブロックされた場合、配布元がこのリポジトリであることを確認し、起動を試した後に「システム設定 → プライバシーとセキュリティ → このまま開く」で、このアプリだけを許可してください。システム全体の保護を無効にしないでください。管理された Mac では実行できない場合があります。


## 猫を置く

1. Finder やブラウザなど、通常のウインドウを開きます。
2. **メニューバーの猫アイコンを押したまま、対象のウインドウへドラッグ**します。緑の枠が対象です。
3. ボタンを放すと、そのウインドウに猫が付きます。
4. アイコンをクリックするとメニューが開きます。操作する猫を選び、散歩・ボール・猫じゃらし・お昼寝を切り替えます。

1 ウインドウにつき 1 匹、最大 12 匹です。同じウインドウに再度ドラッグすると既存の猫を選びます。猫はウインドウの移動やサイズ変更に追従し、最小化や非表示時には隠れ、閉じると回収されます。アプリを切り替えても対象は変わりません。終了すると配置はリセットされます。猫はマウスクリックを妨げません。

メニューから一時停止、速度調整、自動お昼寝、猫の回収、言語変更、終了もできます。言語は即時反映・保存されます。

## 権限とトラブル対応

基本操作にはアクセシビリティ権限も画面収録権限も不要です。ウインドウの位置・識別子・プロセス情報を利用します。スクリーンショット、文書の読み取り、通信、分析データの送信は行いません。

任意の追従強化を使う場合は、「システム設定 → プライバシーとセキュリティ → アクセシビリティ」で現在のアプリを許可して再起動してください。許可しなくても通常の追従は利用できます。

起動だけでは猫は配置されません。上部のアイコンからドラッグしてください。アイコンが見えない場合はノッチやメニューバーの混雑を確認してください。猫が隠れた場合は対象ウインドウを表示してください。Mission Control、ステージマネージャ、フルスクリーン、複数ディスプレイには未検証の制約があります。

不具合は macOS バージョン、機種、再現手順とともに [Issues](https://github.com/kokoro-ele/window-cat/issues) へ。個人情報を含む画像は投稿しないでください。

猫の素材は [Elthen](https://elthen.itch.io/2d-pixel-art-cat-sprites) によるものです。独自の利用条件があり、素材としての再配布はできません。元のスプライトシートはソースリポジトリには含まれません。
